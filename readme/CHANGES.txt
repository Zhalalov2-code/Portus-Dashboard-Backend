🎯 FEATURE OVERVIEW
════════════════════════════════════════════════════════════════════════════

What Users Can Do:
  1. Open LKW Liste or Chassi Liste
  2. Click on any "Notizen" cell
  3. Modal dialog opens
  4. Type notes (e.g., "TÜV: 15.03.2024, SP: 20.04.2024")
  5. Click "Speichern" (Save)
  6. Text appears in table cell
  7. Notes persist after page refresh

Technical Details:
  • Data stored in: lkw.notizen, chassi.notizen (TEXT columns)
  • API endpoint: PUT /api/lkw, PUT /api/chassi
  • Frontend state management: React NotizModal component
  • Type safety: TypeScript interfaces updated
  • Internationalization: Ready for i18n
